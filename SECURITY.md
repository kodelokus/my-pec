# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue. On GitHub, open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and which version you used. Never include a real API key; use a placeholder.

We aim to reply within a week and to tell you when a fix is released.

## What counts

Anything that could expose a user's API key or their companion's files, let a webpage or a model reply run code or reach the core outside the app's fixed set of commands, or send data anywhere other than the Claude API.

The design and its security model are in [docs/architecture.md](docs/architecture.md), section 12.
